# Ethical Use of AI

AI tools were used to help generate and organize parts of this project's code and documentation.

The student reviewed, modified, tested, and understood the project before submission. Any generated code was adapted and checked by the student rather than accepted without review.

This project is for academic learning. The student remains responsible for explaining the architecture, verifying that the application and Terraform behave correctly, protecting credentials, following course rules, and citing AI assistance when required by the instructor.
